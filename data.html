Data

COVID-19 medical announcements dataset

The hand-collected dataset behind the announcements study: 15,839 announcements from 20 countries, January 2020 to February 2022, time-stamped to the minute (UTC).

Replication Package

Python, R, and MATLAB code that reproduces the paper's figures and tables, with a README in each folder.

Get the Package
ColumnDescription
timeMinute-level timestamp of the announcement, in UTC.
countryCountry code: AR, AU, BR, CA, CH, CL, CN, CN-HK, CO, DE, ES, FR, IN, IT, JA, KR, MX, NZ, UK, US.
categorycases (case counts released), live (live-streamed press conference), president speech (led by the President or Prime Minister), or other.
peak1 if the announcement came at the country's usual briefing time (regularly scheduled), 0 otherwise.

In the replication package, only the announcements file is actual data. Newspaper tweet text and proprietary financial series (e.g. Bloomberg, Thomson Reuters, EPFR) are replaced by pseudo data because of provider sharing policies.
